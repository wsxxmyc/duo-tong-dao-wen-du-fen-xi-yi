# 迁移与兼容性说明

> 本开源工程由内部工程整理而来。此文档记录**有意为之的差异**与**兼容性边界**，
> 供后续维护者理解取舍，避免“还原旧行为”造成回退。

## 1. 品牌与命名清理

- 产品统一命名为**多通道温度分析仪**；历史品牌与旧产品代号（串口协议代号、
  竞品主题代号等）已从代码、资源与文档中移除。
- 环境变量 `MTA_HOME`（启动器注入应用根）；`.tpx` 文件关联注册表 ProgID 为
  `MTA.TPXData`，类型描述「多通道温度分析仪数据文件」。
- 局域网广播协议字段 `APP_IDENTIFIER = "MTA-TEMP-ANALYZER"`，默认设备名
  「多通道温度分析仪」。**与旧版标识互不兼容**：新旧版本互相发现 / 配对会失败，
  属重开基线的预期行为，不做双标识兼容。
- 保留的中性例外：`.tpx` 二进制**文件头魔数字节**仍是格式规范的一部分
  （`utils/core.py` 解析与 `device/datastore/tpx_writer.py` 写出），改动即破坏数据
  文件兼容，故不替换；除此之外代码中不再出现旧代号。

## 2. 主题键变更

- 内置主题 `grey_industrial`（浅灰工业）为原内部键更名，色值与交互不变；
  用户旧 `settings.json` 中的历史主题键不受影响（未知键自动回退默认主题）。

## 3. 未随开源版发布的能力

| 能力 | 状态 | 原因 |
|------|------|------|
| 旧版本 `%APPDATA%` 数据迁移弹窗 | 已移除 | 开源基线无旧安装用户 |
| 自动化测试套件 | 未收录 | 本次迁移范围仅业务源码；回归靠 `docs/验证清单.md` 手工项 |
| 内部开发日志 / 审计 / 交接文档 | 未收录 | 内部过程记录不适合公开发布 |
| 厂商协议参考源码与说明书 | 未收录 | 属第三方保密资料；本仓库仅保留协议的行为实现 |

## 4. 许可证基线

- 2026-09-11 拍板：以 **GNU GPL-3.0** 发布（`LICENSE` 为官方全文）。原因：PyQt5 为
  GPL / 商业双许可，未持 Qt 商业授权时，GPL-3.0 是合规的开源分发方式；迁移早期
  曾短暂采用 MIT，因上述冲突已废弃，全仓不再有 MIT 声明。
- 内置字体 Noto Sans SC 采用 SIL OFL 1.1（`assets/fonts/OFL-1.1.txt`），可随包分发。

## 5. 运行兼容基线（勿破坏）

- 不升级 PyQt6 / Python 3.10+：Win7 支持依赖 Python 3.8 构建线与 Qt5。
- 内置字体禁止可变字体（构建门禁强制）。
- 串口 / 线程 / 路径行为变更需按 `docs/验证清单.md` 补真机回归。
