# 验证清单（发布前逐项执行）

> 分级参考：纯逻辑改动 → 定向检查；跨模块 / 主题 / 绘图 → 全量冒烟；
> 触及串口 / 线程 / 打包 / 依赖 → 必须含构建与目标机项。

## A. 代码健康（每次合并前）

- [ ] `python -m compileall src main.py version.py build/launcher.py build/build_win.py` 通过
- [ ] 旧品牌 / 旧代号扫描：按 docs/迁移与兼容性说明.md 列出的历史命名与协议代号模式
      （含其大小写、连字符变体）检索全仓库 —— 源码与资源 0 命中（魔数字节例外）
- [ ] `grep -rn "C:\\\\Users\|F:\\\\" src main.py build --include='*.py'` 无个人机器路径
- [ ] 无 `from x import *`、无裸 `except:`、新增公共接口有 docstring

## B. 功能冒烟（Windows 桌面）

- [ ] `python main.py` 启动主窗口，窗口标题为「多通道温度分析仪」，无异常弹窗
- [ ] 打开样例数据（任意 .csv/.txt）→ 曲线 / 统计 / 通道对比正常
- [ ] 主题切换全矩阵：深浅互切无残留、图表导出背景跟随主题
- [ ] HiDPI（125%/150%）无截断；最小窗口尺寸核心控件可用
- [ ] 导出 PNG / Excel / A4 报告内容完整、单位与通道名一致

## C. 采集链路（无真机时标注「模拟验证」）

- [ ] 模拟设备：连接 / 暂停 / 继续 / 停止 / 重连全路径线程安全退出
- [ ] 特殊值（通道关闭 / 溢出 / 开路）不参与统计
- [ ] CRC / 帧解析单元测试向量通过（如随仓库补充）
- [ ] 真机：RS232 实机握手、8 通道 × 组数识别、掉线重连 —— **未执行必须标注**

## D. 打包与目标机

- [ ] Win10/11 x64 onedir 构建成功，产物冒烟启动
- [ ] Win7 x86/x64 构建成功（Python 3.8.10 环境），**Win7 SP1 真机**：
      启动、中文字体无断笔、串口采集、导出图片
- [ ] 字体静态门禁生效（注入 VF 测试样本应拒绝构建）
- [ ] 发布包不含 `用户数据/`、日志、个人信息（抽查 settings.json / db）

## E. 开源发布检查（建仓前一次性）

- [ ] 全新 orphan 仓库或 `git filter-repo` 清洗后重建：历史无旧品牌、无厂商协议
      参考源码、无真实采集样本、无 API key（任何历史提交 `git log --all -S` 查不到）
- [ ] 若曾内置过真实密钥：已吊销 / 轮换
- [ ] LICENSE / README / requirements / 文档链接自洽（相对路径 0 断链）
- [ ] `git init` 新仓导入本目录后 `git status` 无被忽略文件混入
