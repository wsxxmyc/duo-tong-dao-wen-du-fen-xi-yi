# 模块架构

> 运行时 `main.py` 将 `src/` 注入 `sys.path`，因此代码内使用顶层包名导入：
> `ui` / `chart` / `device` / `utils`。

## 1. 分层与依赖方向

```
main.py
  └─> src/ui/main_window.py        # 主窗口编排、信号连接、跨组件协调
        ├─> src/ui/widgets/        # 可复用界面组件（通道卡、面板、悬浮球/弹窗等）
        ├─> src/ui/dialogs/        # 设置与调参对话框
        ├─> src/ui/theme.py        # 主题引擎（颜色常量 + QSS + matplotlib 暗色参数）
        ├─> src/chart/             # 绘图引擎：chart_renderer / chart_tab / series_sampler
        ├─> src/device/            # 设备与数据链路（不触碰 Qt 控件）
        │     ├─ acquisition.py    # 串口协议编解码 + 采集线程（pyserial）
        │     ├─ datastore/        # 统一数据总线：buffer/store/pipeline/recorder/loader/session
        │     ├─ database/         # SQLite 历史持久化（history_db/dao/migrations）
        │     └─ network/          # 局域网远程访问（TCP/HTTP/配对码 + client + firewall）
        └─> src/utils/             # core.py（纯数据模型与分析）+ 配置/导出/字体/报警音/Modbus
```

约束：

- `device`、`utils` 不得导入 `ui`；`ui` 经回调 / 信号与下层交互（历史遗留的
  `utils/export.py` 引用主题常量属渲染需要，保持单向，无循环）。
- Qt 控件只在 GUI 主线程创建更新；后台线程一律通过 `pyqtSignal` 传数据 / 状态 / 错误。
- 主题颜色必须用 `Theme` 语义化常量，不散落硬编码色值。

## 2. 数据流

```
串口帧 bytes ─> AcquisitionProtocol 解码 ─> 采集线程 pyqtSignal
   ─> DataStore/Buffer（环形缓冲、降采样） ─> MainWindow 刷新绘图（chart.*）
   ─> Recorder（批量写 SQLite） ─> HistoryDatabase ─> 「数据」弹窗 / 远程服务
文件路径 ─> loader ─> core.Dataset（.xls/.csv/.txt/.tpx 解析） ─> Session ─> 同上
```

- `.tpx` 二进制格式解析 / 写出位于 `utils/core.py` 与 `device/datastore/tpx_writer.py`；
  文件头魔数字节与某些温度测试仪配套软件兼容（格式说明见 tpx_writer 模块 docstring）。
- 设备特殊值（通道关闭 / 溢出 / 热电偶开路）保留为明确无效状态，不参与统计。

## 3. 配置与用户数据

- 运行配置：`用户数据/config/settings.json`（缺失 / 损坏 → 内置默认值 + 可诊断降级）；
  `ConfigWatcher` 监听外部修改。
- 历史数据库：`用户数据/data/temperature_history.db`；日志：`用户数据/logs/`。
- 应用根解析优先级：环境变量 `MTA_HOME`（启动器注入）> 冻结模式 exe 目录 > 源码模式项目根。

## 4. 主题引擎

`ui/theme.py` 统一管理：颜色常量（`BG_PRIMARY/TEXT_MUTED/ACCENT/...`）、全局 QSS、
matplotlib rcParams、通道色板与导出背景。主题集含浅灰工业（`grey_industrial`）等
工业 HMI 风格；切换时全量重放样式与图表主题，避免残留。

## 5. 版本与打包

版本唯一事实源 `version.py`；`build/build_win.py` 校验 Python 版本与位数后驱动
PyInstaller（spec 读取 env 或 version.py 注入版本资源）。详见 `docs/打包指南.md`。
