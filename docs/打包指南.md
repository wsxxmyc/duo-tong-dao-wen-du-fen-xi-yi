# 打包指南

> 完整约定（构建矩阵、命名规则、目标机前提、兼容门禁）见 [build/PACKAGING.md](../build/PACKAGING.md)，
> 本文件只做快速索引。

## 支持矩阵（4 种组合）

| 维度 | 取值 |
|------|------|
| 目标系统 | `--profile win10`（Python 3.9.x）/ `--profile win7`（Python 3.8.10） |
| 架构 | `--arch x86` / `--arch x64`（由构建机解释器位数决定，可省略自动探测） |
| 形态 | `--bundle onedir`（推荐，含根目录启动器）/ `--bundle onefile` |

## 常用命令

```bat
:: Win10/11 x64 目录版
python -m pip install -r build/requirements_build.txt
python build/build_win.py --profile win10 --arch x64 --bundle onedir

:: Win7 x64 目录版（务必在 Python 3.8.10 x64 环境执行）
python -m pip install -r build/requirements_build_win7.txt
python build/build_win.py --profile win7 --arch x64 --bundle onedir
```

- 产物自动归档到 `发布版本/v<版本>/多通道温度分析仪_v<版本>_<日期>_第<N>版_<架构>[_Win7]/`。
- `--edition N` 记录同一版本第 N 次打包；正式版本自动生成 VERSION / RELEASE_NOTES / PACKAGE_MANIFEST。

## 关键约定

1. **字体门禁**：`assets/fonts/` 只允许静态实例（SIL OFL）。构建前自动扫描，发现
   fvar（可变字体）即拒绝构建——Win7 DirectWrite 不支持 VF，会导致中文断笔。
2. **版本单源**：升级版本只改根目录 `version.py`；spec 与 exe 版本资源自动注入。
3. **绿色版**：运行时数据写 `用户数据/`，推荐 onedir + 可写目录安装位置。
4. **Win7 真机验证**：发布前按 `docs/验证清单.md` 在 Win7 SP1 目标机执行串口与界面验证。
