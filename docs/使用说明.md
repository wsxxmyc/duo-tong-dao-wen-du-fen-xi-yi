# 使用说明

> 面向最终用户的快速上手指南。界面文案均为中文，术语与本仓库代码一致。

## 1. 启动与主界面

- 双击发布包根目录的 `多通道温度分析仪_v<版本>.exe`（目录版启动器），或运行
  `程序文件/` 内主程序；源码运行见 README。
- 主界面自上而下：工具栏 → 采集控制面板 / 通道列表 → 趋势图区（整体趋势 /
  组合图 / 通道对比标签页）→ 底部状态栏。
- 高 DPI 自动缩放；推荐窗口尺寸下布局完整，最小尺寸下核心控件不截断。

## 2. 离线数据分析

1. 工具栏「打开」或直接双击 / 拖入数据文件（`.xls/.xlsx/.csv/.txt/.tpx`）。
2. 导入后可在各标签页查看趋势；「回到最新」恢复全量视图。
3. 统计面板显示每通道均值 / 最值 / 标准差；支持按时间窗裁剪。

## 3. 串口在线采集

1. 「采集设置」中选择 COM 口（支持自动扫描与端口记忆）、波特率（支持自动遍历，
   默认常用 2400）、协议版本（自动检测 / 新版 / 旧版）。
2. 开始采集后通道实时刷新；特殊值（通道关闭 / 溢出 / 热电偶开路）显示为无效，不参与统计。
3. 暂停 / 继续 / 停止均安全退出采集线程；异常断开自动重连（重试次数可配）。
4. 报警：设置上下限后触发视觉 / 声音提示；持有 Modbus RTU 继电器模块时可联动开关量输出。

## 4. 历史与远程

- 「数据」入口集中管理本机会话（SQLite 历史库）与远程设备：
  局域网内另一端开启「远程访问」服务后，本程序可凭配对码发现并拉取其历史数据。
- 首次使用建议运行「防火墙检测」，一键放行为本程序新建 UDP/TCP 规则。
- 远程拉取在后台线程执行，界面不冻结；服务端与客户端模式互斥。

## 5. 主题与显示设置

- 设置页支持多套工业 HMI 主题（含深色产线与浅灰工业两套典型风格）、通道配色、
  字体四档（pt 单位，随 HiDPI 缩放）、坐标轴与时间轴配置。
- 通道卡 / 列表双风格可即时切换；通道显隐、重命名、分组在左侧面板完成。

## 6. 导出

- PNG 图表、Excel 数据、分析报告、A4 横向报告（含底部统计表）经统一导出对话框
  勾选任务批量执行；导出遵循当前主题（含暗色图表背景）。
- 导出默认不静默覆盖：目标文件存在时提示确认。

## 7. 悬浮球与监控弹窗

- 采集进行中桌面出现悬浮球，单击弹出实时监控窗（时间窗口滑块 5~120s）；
  托盘菜单可整体开关悬浮球生态。

## 8. 数据与配置位置

- 所有用户数据写入程序同级 `用户数据/`（config / data / logs）；
  `settings.json` 损坏时按内置默认值降级并在日志提示。
- 移动整个软件文件夹即带走全部数据；请勿在 Program Files 等只读位置运行。

## 9. 故障排查速查

| 现象 | 处理 |
|------|------|
| 启动报缺少 VCRUNTIME140.dll | 安装 VC++ 2015-2019 运行库（Win7 另需 KB2999226） |
| 串口无响应 / 乱码 | 核对波特率与协议模式；用「自动检测」再试 |
| 远程设备互搜不到 | 双机防火墙检测放行；确认同网段（支持多网卡选择） |
| Win7 中文断笔 | 使用官方发布包（内置静态字体），勿替换为可变字体 |
| 导出图片界面元素缺失 | 检查主题导出开关与图例设置；离屏环境仅影响无头渲染 |
